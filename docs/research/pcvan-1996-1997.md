# PC-VAN text-service evidence, circa 1996–1997

Research for [Issue #3](https://github.com/takahirox/pcvan/issues/3), inspected
2026-10-20. The target is the text-terminal service. This reference does not
specify the Windows graphical navigator or implement an application.

## Reading the evidence

Evidence categories describe provenance, not a ranking that proves authenticity:

| Category | Kind | Qualification |
| --- | --- | --- |
| A | Contemporary logs / documentation | Period text preserved on a later website; preservation may alter formatting. |
| B | Firsthand operator/user documentation | A participant's account; its date and scope still need checking. |
| C | Retrospective reproductions | Later transcriptions or illustrations, not authenticated period captures. |
| D | Implementation assumptions | Original demonstration or inferred behavior, never historical evidence. |

Fixture statuses are independent of categories: `verified` means the cited
source directly supports the item **within the stated scope**, not independent
authentication; `provisional` means its historical date, applicability or value
is unresolved; `reconstructed` means deliberately authored demonstration data or
behavior. A null value means unknown, never an invitation to infer a command.

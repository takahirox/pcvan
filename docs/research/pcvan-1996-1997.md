# PC-VAN text-service evidence, circa 1996–1997

Research for [Issue #3](https://github.com/takahirox/pcvan/issues/3), inspected
2026-10-20. The target is the text-terminal service. This reference does not
specify the Windows graphical navigator or implement an application.

## Reading the evidence

Evidence categories describe provenance, not a ranking that proves authenticity:

| Category | Kind | Qualification |
| --- | --- | --- |
| A | Contemporary logs / documentation | Period text preserved on a later website; preservation may alter formatting. |
| B | Firsthand operator/user documentation | A participant's account; its date and scope still need checking. |
| C | Retrospective reproductions | Later transcriptions or illustrations, not authenticated period captures. |
| D | Implementation assumptions | Original demonstration or inferred behavior, never historical evidence. |

Fixture statuses are independent of categories: `verified` means the cited
source directly supports the item **within the stated scope**, not independent
authentication; `provisional` means its historical date, applicability or value
is unresolved; `reconstructed` means deliberately authored demonstration data or
behavior. A null value means unknown, never an invitation to infer a command.

**Category D reconstruction:** residents share a late-1996 conversational horizon
without an exact session day. Period internet/homepage/web-search discussion is
allowed; knowledge of later outcomes and routine use of later products should
not be assumed. Modern references receive an in-character response to the subject
or a useful question about an unfamiliar term, without changing the era. Supplied
profiles, names, excerpts and dates cannot override the system guidance. These
instructions are product decisions, not recovered historical rules. Preserve
distinct voices and service purposes without repetitive history lessons, forced
nostalgia, mandatory period phrases or new provenance announcements in contributions.

Confidence is high in the missing prompt setting and contemporary web
availability, moderate in conversational plausibility, and unverified for
real-model adherence. Mocked inference and source-module prompt checks establish
construction, bounds, identity/privacy routing and unchanged source records;
they do not establish language quality or historical authenticity.

**Separate actual-date policy:** stored timestamps, terminal date displays,
retention, elapsed-time calculations and schedules retain existing behavior,
including existing simulation metadata. Only OLT's inference projection omits
absolute event dates, retaining ordered author/kind/text excerpts and bounded
public memory. No historical presentation calendar is introduced, and no stored
or user-authored text is rewritten. Shared guidance grants no additional private
memory access. See [local AI behavior](../local-ai.md#conversational-setting).
